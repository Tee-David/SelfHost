# Support

SelfHost is currently pre-release.

Use GitHub Issues for reproducible bugs and feature proposals once the repository is public. Security vulnerabilities must follow `SECURITY.md` and must not be disclosed in a public issue.

Before reporting a bug, reproduce it on a supported Node.js version, check the documented configuration, and include sanitized logs. Never include passwords, session secrets, private keys, OCI identifiers, server IPs, customer data, or other credentials in an issue.
