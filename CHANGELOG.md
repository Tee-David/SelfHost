### Added

- Clean-room SelfHost project foundation.
- Runtime configuration validation with optional OCI integration.
- Constrained no-shell privileged command runner.
- Initial allowlisted Hestia read adapter.
- Session signing and hardened cookie policy.
- Replaceable rate-limiter interface with single-process implementation.
- Filesystem path and filename safety boundary.
- Security, architecture, source-audit and release-readiness documentation.
- TypeScript security tests and continuous integration.
